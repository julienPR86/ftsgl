# FTSGL - A simple openGL library

## Description

ftsgl is a personal opengl library, on which I am currently working on, in order to learn the basics of graphical rendering.

I am using [GLEW](https://glew.sourceforge.net/) as the extension loading library.

## Requirements

- [opengl](https://www.opengl.org/)
- [glew](https://glew.sourceforge.net/)
- [glfw](https://www.glfw.org/)
- [make](https://www.gnu.org/software/make/manual/make.html)

## Instructions

To compile and build to project, just run:

```sh
make
```
